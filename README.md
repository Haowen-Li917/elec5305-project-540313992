# ELEC5305 Project

## Speech Enhancement in Noisy Environments Using STFT-Based Wiener Filtering

This project investigates speech enhancement in noisy environments using Short-Time Fourier Transform (STFT) analysis and Wiener filtering.

The aim is to reduce background noise in speech recordings while preserving speech quality and intelligibility. The system will be implemented in MATLAB and evaluated using objective measures such as Signal-to-Noise Ratio (SNR), together with waveform and spectrogram comparisons.

## Proposed Method

- Speech and noise signal preparation
- STFT-based time-frequency analysis
- Noise spectrum estimation
- Wiener filtering
- Inverse STFT signal reconstruction
- SNR and spectrogram-based evaluation

## Software

- MATLAB R2024a
- Signal Processing Toolbox
